## 📌 Overview

Ascend-OS is a personal engineering dashboard designed to help me manage and track my goals, routines, habits, schedules, and learning progress in one centralized place.

The project was created to solve my own challenge of managing multiple separate goal trackers, habit trackers, and schedule systems. Instead of using disconnected tools, Ascend-OS brings everything together into a personalized dashboard that matches my workflow, routines, and long-term objectives.

The goal of this project is not only to build a useful productivity system for myself but also to improve my engineering skills by designing, developing, and continuously improving a real-world application.

Unlike generic productivity tools, Ascend-OS is tailored around my personal goals, habits, and development journey, making it a constantly evolving system that grows with me.

# 🛠 Tech Stack

## Frontend

- React
- Tailwind CSS
- React Router
- Context API
- Recharts for analytics
- React Hook Form
- localStorage (v1)

## Backend

- FastAPI
- SQLAlchemys
- PostgreSQL
- JWT Authentication

## Deployment

- Vercel (frontend)
- Railway/Render (backend)
- Neon PostgreSQL
